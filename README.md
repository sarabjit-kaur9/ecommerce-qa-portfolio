

Welcome to my Software Quality Assurance (QA) Portfolio!

This repository showcases my knowledge and practical work in software testing, with a focus on e-commerce applications. It is designed to demonstrate my understanding of manual testing, test case design, defect reporting, and test automation.

My goal is to help ensure that e-commerce applications deliver a reliable, user-friendly, and high-quality shopping experience.

Project Overview

This portfolio focuses on testing key e-commerce functionalities, including user authentication, product browsing, shopping cart management, and the checkout process.

The objective is to identify potential defects, validate expected application behaviour, and document testing activities using industry-standard QA practices.

Testing Scope

The following areas are included in the portfolio:

User Authentication: Login validation, invalid credentials, and input validation.
Product Catalogue: Product listings, product details, and search functionality.
Shopping Cart: Adding items, removing items, and updating quantities.
Checkout: Checkout form validation, delivery details, and order placement.
Form Validation: Required fields, invalid inputs, and error messages.
Regression Testing: Verifying that existing functionality continues to work after changes.

Sample Test Scenario

Scenario: Verify that a user can add a product to the shopping cart.

Precondition: The e-commerce application is accessible, and a product is available.

Test Steps:

Open the e-commerce application.
Navigate to the product catalogue.
Select an available product.
Click the Add to Cart button.
Open the shopping cart.

Expected Result: The selected product appears in the shopping cart with the correct product details and quantity.

Actual Result: To be recorded during test execution.

Status: Not executed.
